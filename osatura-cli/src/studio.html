Selection

Click picks the topmost thing (locked and hidden ones are skipped); Shift-click toggles; drag on empty space draws a box (hold Alt to draw a free-form lasso, Shift adds). Drag the box to move, a square to scale (Shift keeps proportions, Alt scales from the centre), the round knob to rotate (Shift snaps to 15 degrees). Hold Ctrl while dragging to switch snapping off. Arrow keys nudge 1 unit (Shift: 10), Delete removes layers, Esc cancels a drag or clears the selection.

Webcam face (optional)

Face landmarks drive the same mapping table (source face, ids such as mouth_open, eye_r_open, head_yaw). OSATURA includes a small detector trained on synthetic (stylised) faces only (button Synthetic face (detector)); it is not validated on photographs or webcams. A real webcam needs a landmark provider of your own: a function you supply (see the comment in the page source) that returns landmarks for each video frame. The synthetic provider shows the pipeline without a camera. Video never leaves the page; only landmarks go to this local server.

Guided demo · walking person

Build a whole character, step by step, with the same commands you would type in a terminal. Each step loads the project that command produced into this editor, so you can play, scrub, select bones and layers, and look at the timeline.

This replaces the project in the editor. Nothing is written to disk: Save is disabled while the demo is loaded, and Restore my project (or Undo) brings your project back.
