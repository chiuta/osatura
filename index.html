What it does

  
Everything between a vector shape and a finished animation

  
One workspace, small deterministic pieces. Every tool reads and writes a documented JSON project, and every command works from a terminal.

  

    
01 · DRAW
Drawing model
Vector paths, fills, strokes with dashes and variable width, linear and radial gradients, masks, blend modes, per-layer effects, image layers with mesh warp, liquid metaballs, polygon booleans, deterministic particles and a multiplane camera with depth of field.
Béziergradientsmasksblend modesmetaballsbooleansparticlesmultiplane camera

    
02 · RIG
Rigging
Bones with FK, two-bone, soft, stretch and FABRIK IK. Limits, constraints, springs, weight tools, lattice, spine, morph and cage deformers, auto-rig from layer names.
FKFABRIK IKskinninglatticepin warp

    
03 · ANIMATE
Animation
Keys with Bézier, step, spring and bounce easing; expressions; layered clip stack; foot lock; chain, hair and cloth physics; lip-sync from audio or a transcript; BVH retargeting; MIDI, mouse, gamepad and webcam-landmark input.

      

    
04 · RUN
Runtime
State machines with 1-D blend trees, data binding, scroll physics, level of detail with an error bound, a Rhai scripting sandbox and an MCP agent server over patch operations.
state machinesblend treesRhaiLODMCP agent

    
05 · EXPORT
Output
From SVG and PNG to GIF, video, Lottie, glTF and a self-contained HTML player.
GIFLottieglTFHTML

    
06 · VERIFY
Quality tooling
check, lint, semantic diff, pose fuzzing, animation CI with golden frames, version control with semantic merge.
lintdiffCIfuzz

    
07 · STUDIO
Browser studio
Gizmos, timeline, dope sheet, graph editor, command palette, undo/redo and real-time multi-user editing.
timelinegraph editorcollab

Determinism

  
Same seed, same pixels

  
Change the seed of run B: the hash changes. Set it equal to A: they match again. That is the property the engine is built on, which makes golden-frame CI possible.

Honest status

  
What is verified, and what is not

  
The project states its limits next to its features. Read LIMITATIONS.md before you depend on anything.

  

    
1,338tests in cargo test --workspace without the GPU and window crates (plus 19 doc-tests), 24 Oct 2026, Linux x86-64; CI also passes on macOS and Windows

    
78numbered limitations, with severity and workaround

    
363third-party crates in the 24 Oct 2026 inventory (all platforms together)

    
1published release so far: v0.1.0-alpha.5, a prerelease; “0.7” is a feature level, not a version

  

  

    
Verified
  • 1338 tests plus 19 doc-tests pass locally (24 Oct 2026, Linux x86-64); the same suite and clippy pass on GitHub Actions for Linux, macOS and Windows
  • The WebAssembly module builds in CI and the wrapper’s test passes against it under Node; cargo-deny and REUSE pass
  • 4 headless-Chromium smoke tests of the studio pass (124, 60, 89 and 35 checks)
  • CLI, Rust facade and C ABI run with the documented examples, also under ASan/UBSan

    
Not verified
  • The WebAssembly module runs in headless Chromium (the “try it” page); no person has measured its speed or memory, or tried it in other browsers
  • Only one person has tried the Windows launcher and the window app (Windows 11, alpha.2); nobody has used them on macOS; the binaries have Sigstore signatures but no Windows or macOS code signature
  • The studio was never used by a person in production, nor in a browser other than Chromium
  • No real GPU, webcam, photograph or motion-capture file was ever used; no security audit, lawyer review or patent search
  • The name OSATURA was searched only at the EUIPO; OSIM, WIPO and a lawyer’s opinion are still open

  

  
Disclosure: the code was largely written with an AI model, and the project is an independent implementation from public specifications; see CLEANROOM.md. It is not affiliated with, derived from or compatible with any commercial animation product.

Architecture

  
Six crates, one workspace

  

    
osatura-core
Engine, formats, tools and the stable Rust facade.
MPL-2.0

    
osatura-cli
The osatura binary, the browser studio and the collaboration server.
AGPL-3.0+

    
osatura-capi
C ABI: header, shared and static library; also run under ASan/UBSan.
MPL-2.0

    
osatura-wasm
WebAssembly ABI and JS wrapper. Built in CI and tested under Node; runs in headless Chromium on the “try it” page.
MPL-2.0

    
osatura-gpu
Optional wgpu renderer, not a default member.
MPL-2.0

    
osatura-gui
The studio in a native window (Windows, macOS). Compiled and self-tested in CI; the window and its exports were tried by one person on Windows 11 (alpha.2); the Save-as dialog is untested.
AGPL-3.0+
