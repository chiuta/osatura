OSATURA Portable @DISPLAY_VERSION@

OSATURA is a 2D rigging and animation studio and command-line engine. This package runs it from a USB drive or any folder, without installing anything and without leaving files on the computer you use.

Using it

  • Start OSATURAPortable: the studio opens in its own window. Close the window to stop it.
  • Your first project, first-rig.json, is created in Data\Projects the first time. Your own projects can live there too.
  • The studio settings are in Data\settings\ui.json; the window component's cache and browser storage are in Data\WebView2. Copy the Data folder to move your settings and projects.
  • The command-line program is App\OSATURA\osatura.exe (run osatura --help in a terminal). It is not redirected: without the launcher it uses your user profile for its settings unless you set OSATURA_UI_CONFIG and OSATURA_DOCUMENTS yourself.

Requirements

  • Windows 10 or 11, 64-bit, with the Microsoft Edge WebView2 Runtime (already part of current Windows 10 and 11; otherwise install it from Microsoft). It is not included in this package.
  • Optional: ffmpeg on the PATH for video export and mp3/ogg audio. It is not included.
  • The studio listens only on this computer (127.0.0.1). A firewall prompt, if one appears, can be answered "cancel"/"block".

Good to know

  • Temporary files (audio mixing, exports) go to the system temporary folder and are normally removed when the command ends.
  • This is an alpha release. Back up your projects.
  • The release files are signed and attested; how to check them: docs/VERIFY_DOWNLOADS.md in the source, or github.com/chiuta/osatura.
